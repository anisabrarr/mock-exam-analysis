# Project Title: Program Performance and Enrolment Analysis

### Overview
This project was developed to evaluate the efficacy of internal academic initiatives and student acquisition strategies. Using Python, the system extracts, cleans, and synthesizes raw operational data from disparate sources (including attendance records and enrolment logs). The insights generated from this analysis provide the team with data-driven metrics on student retention, program engagement, and acquisition trends to inform long-term strategic decisions.

### Tech Stack & Tools
* **Languages:** Python
* **Libraries/Frameworks:** fs, PapaParse, Node.js

### Key Features
* code cross-references customer touches across three distinct datasets (before-program, after-program, and acuity registration data) using custom-built identifier indexing (email or normalized phone strings) to automatically map a student's exact conversion journey
* Implemented case-insensitive regex pattern matching to dynamically parse messy, manual appointment type logs and accurately route them into their target academic cohorts (Chemistry, Physics, or Mathematics).

### Impact / Results
* Delivered direct clarity to the Management Team by generating precise conversion metrics, pinpointing exactly how many students successfully converted to active students after exam initiative
* Replaced time-consuming manual tracking with an instantaneous, automated terminal script that extracts data from hundreds of disparate rows across multiple system logs
